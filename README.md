# SIH-project: ArtisanBridge AI

> Multilingual, Voice-First AI Commerce & Smart Cataloguing Platform for Rural and Traditional Artisans.

## Features
- **Voice-First Navigation & Intent Recognition**: Multilingual voice commands across Indian regional languages (Tamil, Hindi, Telugu, etc.).
- **Smart Cataloguing**: Automated craft quality analysis, background removal, title and description generation.
- **Direct Market Linkage**: Matches artisans with bulk buyers, exporters, and retail customers.
- **Offline & Low-Bandwidth Support**: Mobile-optimized progressive web app.

## Tech Stack
- **Frontend**: React 18, Vite 6, Vanilla CSS, Lucide Icons, Canvas Confetti
- **Deployment**: Netlify (configured via `netlify.toml` and SPA `_redirects`)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
The output will be in the `dist/` directory.
